## Filling this table

`scripts/fill_credits.py` fills the author and licence columns from
`sign_library/library_index.csv` (offline). Files still missing data are
listed by the script; run it with `--online` to query the Wikimedia Commons
API for those and write the results back into the index:

```
python3 scripts/fill_credits.py            # offline, from the local index
python3 scripts/fill_credits.py --online   # query Commons for the remainder
```
