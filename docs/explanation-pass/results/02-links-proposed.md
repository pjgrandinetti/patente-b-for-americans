## 20061 (FALSO)

*Il segnale raffigurato è un segnale di corsia*

The sign shown is a lane sign.

**Link added:** False. This is a mandatory-direction sign: a blue circle with a single arrow, which orders every vehicle to go straight at the point where it stands. A lane sign (segnale di corsia) looks different: it is a square or rectangular blue panel drawn as a map of the carriageway, with one arrow for each lane. Symbols on an arrow say how that lane may be used, for example [a ban on trucks over 3.5 t in the left lane], [a minimum speed for each autostrada lane], [a lane reserved for buses], or a lane being added or taken away. So a round sign with one arrow is never a lane sign.
