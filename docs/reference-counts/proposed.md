# Reference page: how many questions test each figure (proposed)

Not applied. "Tested" counts every question you need that figure to answer, true or false, including a false one that offers a different figure. "Cited" is how many the page cites today. Rows marked "number not tested" (the Code's points for violations the bank never prices) would show no count.
